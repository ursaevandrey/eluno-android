# Eluno — E · Контакт

01.11.2026 пользователь выбрал третий концепт Logo Design Skill: мягкая прописная E с отдельной точкой контакта. По последующему прямому запросу все прежние варианты и листы концепций удалены. В дизайне используется только этот знак.

## Файлы

- `symbol.svg` — мастер 256×256, два залитых контура, без шрифта, растра и фильтров.
- `symbol-black.svg`, `symbol-white.svg`, `symbol-lavender.svg` — тот же знак в одном цвете.
- `eluno-app-icon.svg` — квадратный цветной оригинал без встроенных скруглений и теней.
- `eluno-app-icon-{16,32,48,192,512}.png` — растровые экспорты.
- `foreground.svg`, `monochrome.svg` — прозрачные слои Android 108×108.
- `android/res/` — VectorDrawable и adaptive-icon для API 26+, monochrome для API 33+.
- `preview.png` — проверенный браузерный предпросмотр.
- `eluno-app-icon.zip` — комплект только выбранной иконки.

## Использование

Фон `#6750A4` (RGB 103,80,164), знак `#F1E8FF` (241,232,255). В одноцветных материалах допускаются чёрный, белый или лавандовый знак. Не поворачивать, не растягивать, не присоединять точку к средней перекладине, не добавлять контуры и тени. Минимальный размер самостоятельного знака — 16px; для прикладного интерфейса предпочтительно 24px и больше. Свободное поле вокруг самостоятельного знака — не меньше диаметра точки (40 единиц мастер-сетки). Launcher использует специальные поля слоёв, а не это правило.

Формы и промежутки сохранены от выбранного концепта. Светлая версия визуально немного тяжелее тёмной; на проверенных 16–48px промежутки остаются открытыми. Отдельная упрощённая геометрия для малого размера не потребовалась. Название на странице — обычная подпись интерфейса, не отдельный утверждённый логотип со шрифтом.

## Android

Скопировать `android/res/` в app-модуль. Указать `android:icon="@mipmap/ic_eluno_launcher"` и `android:roundIcon="@mipmap/ic_eluno_launcher_round"` в application manifest. Android-проект в этой задаче не изменён.

Слои 108dp, foreground преобразует мастер масштабом 0.225 и сдвигом 25.2 по обеим осям. Габариты знака 37.8×39.6dp; знак помещается внутри центральной безопасной окружности диаметром 66dp. Фон непрозрачный и заполняет слой. Скругление и цвет monochrome назначает лаунчер. Предпросмотр показывает центральную область 72×72 с масками; themed-цвета иллюстративные. Для текущего minSdk 28 legacy PNG в mipmap не нужны.

Основа: [Android Adaptive Icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive), проверено 01.11.2026.

## Проверки и передача

SVG и XML разобраны, pathData обоих Android-слоёв совпадают с мастер-знаком; формы проверены в браузере на светлом и тёмном фоне, круглая маска и размеры 16/24/32/48px. Проверка защищённых файлов прототипа пройдена. Нативная установка и поведение на физических лаунчерах не проверялись; это следующий шаг при интеграции. Права на товарный знак отдельным поиском не проверялись.
