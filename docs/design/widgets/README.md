# Виджеты Eluno — 01.11.2026

Актуальный запрос пользователя: два вида, горизонтальный 1×2 и квадратный 2×2. Здесь 1×2 означает одну строку и два столбца. При нативной настройке не путать этот порядок с обозначением ширина × высота: горизонтальный вид занимает две ячейки по ширине и одну по высоте.

- 1×2: название слева, круглая кнопка питания справа.
- 2×2: название сверху, круглая кнопка питания снизу, оба элемента по центру.
- Внутри виджета только название и кнопка питания. Размеры и подписи состояний снаружи — пояснения макета, не часть виджета.
- Иконка питания — точный SVG Eluno Outline из `../icons/svg/power.svg`, без перерисовки.
- Включено: лавандовая поверхность и акцентная кнопка. Выключено: нейтральная поверхность и приглушённая кнопка.
- Предусмотрены светлая и тёмная темы. Кнопки 56px в горизонтальном виде, 72px в квадратном; знак питания 26/32px соответственно. Скругления контейнеров 28px в макете.
- Макет не задаёт абсолютный размер ячеек лаунчера: фактическая компоновка адаптируется к доступной области.

Предпросмотр: `design-prototype/public/widgets/index.html`, снимок `preview.png`. Кнопки переключают демонстрационное состояние, название ведёт в прототип приложения. Реальные команды устройству не отправляются. Проверено переключение туда и обратно в браузере, обе темы и геометрия двух видов. Проверка runtime пройдена.

Этот дизайн заменяет прежнюю визуальную линейку compact/wide/large. Нативная реализация и её состояния ожидания/ошибок остаются отдельной задачей; реальное состояние необходимо менять после подтверждения команды. Следующий шаг — обратная связь по макету, затем перенос в Android.
