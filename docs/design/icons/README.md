# Eluno Outline

Создано 1 ноября 2026. Собственный согласованный набор из восьми контурных иконок: лампа, розетка, светодиодная лента, настройки, питание, универсальное устройство, сканер QR и свет.

## Файлы

- `svg/`: векторы для дизайна и веба, цвет через `currentColor`.
- `android/`: соответствующие VectorDrawable для `res/drawable/`.
- `../../../design-prototype/src/eluno-icons.json`: те же контуры для React-компонента `ElunoIcon`.
- Просмотр: `/icons/index.html` в локальном прототипе.

## Правила

Сетка 24×24, stroke 1,75 единицы, round cap и round join. Масштабировать пропорционально, не растягивать по одной оси. Размеры интерфейса: 24–28 dp для действий, 34–42 dp для устройств; область касания минимум 48×48 dp. Не смешивать иконки набора с прежними MDI/Phosphor аналогами.

Питание использует одинаковый контур во включённом и выключенном состоянии. Различие создают заливка кнопки, контраст и текстовая подпись; pending и offline остаются отдельными состояниями. Цвет наследуется от смысловой роли темы, не зашивается в SVG. Android XML содержит чёрный базовый stroke: при использовании через Compose `Icon(painterResource(...), tint = ...)` задавать цвет темы. Контуры собственного набора не требуют стороннего иконочного шрифта.

SVG и VectorDrawable имеют одинаковые pathData. При изменении обновить все три представления, галерею и снимки. В Android проверить рендер на API 28+ в 24/32/48 dp; нативная проверка в текущем ходе не выполнялась.

Кнопке задавать доступное название, например «Выключить: Настольная лампа». Декоративная иконка внутри подписанной кнопки не требует повторного описания.

## Универсальное устройство
`device.svg` / `ic_eluno_device.xml` — нейтральный прибор для неизвестного или неподдержанного типа. Выбор значка не меняет capabilities и не означает ошибку или недоступность. В прототипе это fallback после явных lamp/outlet/strip; состояние stale само по себе не определяет тип реального прибора.

01.11.2026: по замечанию пользователя универсальный значок переработан в симметричный модуль с контактами. Прежний силуэт прибора с экраном отклонён. Новая геометрия сохраняет сетку 24×24 и линию 1,75.

## Сканер QR
`qr-scanner.svg` / `ic_eluno_qr_scanner.xml`: рамка сканирования и условные QR-маркеры, не настоящий QR-код. Для будущего действия «Сканировать QR-код» при подключении устройства; доступное имя задаётся кнопке. Добавление ресурса не означает реализации камеры или commissioning.

01.11.2026: QR-сканер переработан по замечанию пользователя: открытые прямые углы рамки вместо коротких дуг, три квадратных маркера и один простой угловой модуль; лишняя точка удалена. Толщина 1,75 и сетка 24×24 сохранены.

## Свет
`light.svg` / `ic_eluno_light.xml` / React key `light` — лампочка для общего обозначения освещения. Отдельна от `lamp` (настольный светильник). Сетка 24×24, линия 1,75, скруглённые окончания. В виджеты по уточнению пользователя не добавляется.
