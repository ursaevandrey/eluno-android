# Eluno — браузерный дизайн-прототип

Основан на выбранном варианте 2. Основной код интерфейса: `src/Prototype.tsx`, стили: `src/prototype.css`.

Запуск: Node.js 24, `npm ci`, `npm run dev -- --host 127.0.0.1 --port 4173 --strictPort`.

Прототип: http://127.0.0.1:4173/ ; галерея: http://127.0.0.1:4173/designs/index.html .

В просмотрщике справа сверху доступны Pixel 10, iPhone и три условных Fold-профиля. Данные остаются в памяти вкладки при смене формата, но сбрасываются при перезагрузке страницы. Команды имитируются, реальные устройства не подключены.

Проверки: `npm run check:runtime`, `npm run build`. Визуальная проверка и браузерные сценарии описаны в `design-qa.md`, доказательства в `qa/`.

Дизайн и ограничения Fold описаны в `../docs/design/DESIGN.md`. Защищённая мобильная оболочка сохранена; по запросу пользователя расширены только профили в `Device.tsx` и условный вывод рамки в `PhoneFrame.tsx`. Их хеши обновлены после проверки. Новые Fold-профили не используют растянутые изображения рамки телефона.

Публикация не выполнялась. Сборка в `dist/` локальная; разрешения на публикацию, коммиты или push не было.
